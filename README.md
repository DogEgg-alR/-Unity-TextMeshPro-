# Unity TextMeshPro 富文本标签编辑器

## 简介

**Unity TextMeshPro 富文本标签编辑器** 是一款完全自包含的纯前端 HTML 工具.整个工具封装在单个 HTML 文件中（约 21KB，无任何外部依赖），只需使用浏览器直接打开即可使用。

该工具提供源码编辑与可视化预览双模式，支持实时双向同步，并内置丰富的快捷工具栏，帮助开发者高效编写、调试和导出 TextMeshPro 富文本标签代码。

## 功能特性

### 1. 灵活的视图模式

- **三种视图切换**：顶部按钮支持在「双栏并排」、「源码编辑」和「可视化预览」三种模式间无缝切换。
- **实时双向同步**：源码编辑区与可视化预览区内容保持实时联动，修改任意一侧，另一侧自动更新。

### 2. 专业的源码编辑器

- **等宽字体支持**：内置 Cascadia Code / Fira Code / Consolas 字体栈，提供极佳的代码阅读体验。
- **Tab 缩进**：完美支持 Tab 键缩进，符合代码编写习惯。
- **实时字符计数**：底部实时显示当前文本字符数，方便控制文本长度。

### 3. 所见即所得的可视化预览

- **实时渲染**：将 TMP 标签实时转换为浏览器可渲染的 HTML，实现真正的所见即所得。
- **可视化编辑**：预览区支持直接编辑（contenteditable），在预览区的修改会自动同步回源码区。

### 4. 分类明确的底部工具栏

- **样式组**：粗体 (B)、斜体 (I)、下划线 (U)、删除线 (S)、上标、下标。
- **颜色组**：内置颜色选择器弹窗，提供 40+ 预设颜色色块，并支持手动输入自定义颜色值。
- **排版组**：左对齐、居中、右对齐、行高、间距、字距调整。
- **特效组**：渐变、旋转、缩放、垂直偏移。

### 5. 统一的模态框交互

- 所有提示与交互统一采用模态框设计，包括 Alert、Confirm、Input 及 Color Picker。
- **参数输入**：点击带参数的工具按钮时，自动弹出输入框。
- **安全确认**：执行清空编辑器等破坏性操作前，会弹出确认弹窗防止误触。

### 6. 便捷的导出与操作

- **一键复制**：点击「复制到剪贴板」按钮或使用快捷键 Ctrl+Shift+C 即可导出代码。
- **代码格式化**：内置「格式化」按钮，一键去除多余空格，整理代码结构。
- **安全清空**：「清空」按钮配合确认弹窗，确保数据安全。

### 7. 优秀的移动端适配

- **响应式布局**：当屏幕宽度 < 768px 时，自动切换为单列纵向排列。
- **工具栏自适应**：底部工具栏按钮支持 flex-wrap 自动换行，避免横向溢出。
- **高度与间距优化**：编辑器与预览区高度自适应，整体 padding 和间距在手机端自动缩小，提升触控体验。

### 8. 护眼深色主题

- 采用 **Catppuccin Mocha** 配色方案（背景色 #1e1e2e）。
- 整体低饱和度配色，有效降低长时间编辑带来的视觉疲劳。

## 支持的 TMP 标签

本工具完整支持以下 TextMeshPro 富文本标签：

| 分类 | 标签 |
|------|------|
| 基础样式 | `<b>`, `<i>`, `<u>`, `<s>`, `<sup>`, `<sub>` |
| 颜色与渐变 | `<color>`, `<gradient>`, `<mark>` |
| 排版与间距 | `<align>`, `<line-height>`, `<space>`, `<cspace>` |
| 变换特效 | `<rotate>`, `<scale>`, `<voffset>` |
| 资源与链接 | `<sprite>`, `<font>`, `<link>`, `<material>` |
| 结构控制 | `<page>`, `<p>`, `<size>` |

## 使用方式

1. **获取文件**：下载本项目的 HTML 文件。
2. **打开工具**：使用任意现代浏览器（Chrome, Edge, Firefox, Safari 等）直接打开该 HTML 文件。
3. **编辑内容**：
   - 在「源码编辑区」直接输入 TMP 标签代码；
   - 或在「可视化预览区」直接进行所见即所得的编辑。
4. **使用工具**：点击底部工具栏按钮，快速插入对应的标签或调整样式。
5. **导出代码**：编辑完成后，点击「复制到剪贴板」按钮（或按下 Ctrl+Shift+C），将代码粘贴至 Unity 项目中。

## 技术实现

- **纯前端架构**：零后端依赖，所有逻辑均在浏览器端运行。
- **双向转换引擎**：基于正则表达式构建 TMP 标签到 HTML 的实时转换引擎，同时支持 HTML 到 TMP 的反向解析与同步。
- **精准光标控制**：使用 selectionStart / selectionEnd API 实现工具栏按钮在光标位置的精准标签插入。
- **剪贴板 API**：优先使用现代 Clipboard API 实现复制功能，并内置降级方案以兼容旧版浏览器。
